\section{Theoretical Framework}

\subsection{Measurement view of LLM-as-a-Judge}

This thesis treats LLM-based evaluators as measurement instruments that map an input (e.g., marketing copy text) to a score that represents an underlying (subjective) construct (e.g., "Quality"). To formalize this, we adopt the framework of Psychometric Latent Variable Theory. Psychometrics concerns itself with the measurement of psychological attributes, called constructs. In psychology, constructs are defined as latent (unobservable) variables underlying human behavior, such as cognitive abilities and personality traits. Assuming constructs can be treated as quantitative (for a discussion, see: \citep{michell1997quantitative}), we can measure them by defining their relationship with manifest (observable) variables ("indicators"). Typically, these manifest variables are measured through item scores on a test. For example, the latent construct of \textit{Extraversion} is measured via items like "Talks a lot" or "Has a lot of energy" \citep{john1991big}. 

The same theoretical principles underlie measurements that are used in Machine Learning (ML), where "gold" labels for supervised learning are sourced by having people rate samples. By supplying the raters with specific criteria, their rating is assumed to be a reliable and valid representation of some underlying construct. 

We hypothesize that a similar approach can be applied to LLMs. As \citet{zheng_judging_2023} and related LLMAJ literature demonstrate, LLMs are capable of mimicking human judgment in evaluation tasks. In psychometrical terms, this implies they are capable of measuring latent variables.

\subsection{Latent Variables Models: Reflective vs. Formative}

Latent variable models define a relationship between manifest and latent variables. Two model types are distinguished: formative and reflective \citep{bollen1991conventional}. They differ in their assumptions about the direction of causality. 

In formative models, the manifest variables are assumed to be the common cause of the latent variable. The canonical example is Socioeconomic Status (SES), which can be defined as the composite of three main features: income, education, and prestige \citep{mcquitty2013structural}. Formally, for a set of manifest variables indexed by $i = 1,2, \dots ,n$, we assume

\begin{equation}
    \eta = \sum_{i=1}^{n} \gamma_i x_i + \zeta
\end{equation}

where $\eta$ is a latent construct, $\gamma_i$ a formative weight, $x_i$ a manifest variable, $\zeta$ the disturbance term. 

In reflective models, the latent variable causes the manifest variables. For example, following a "g-factor" interpretation of the latent variable intelligence \citep{spearman1961general}, we assume that intelligence is an inherent trait that humans possess which causes people's performance on cognitive tasks. Formally, for any given manifest variable $i$, we assume

\begin{equation}
    x_i = \lambda_i \eta + \varepsilon_i
\end{equation}

where $x_i$ is a manifest variable, $\lambda_i$ a factor loading, $\eta$ the latent construct, and $\varepsilon_i$ the measurement error.


These definitions have consequences for construct operationalization. In the formative model, the latent variable is defined by its constituents. Therefore, omitting one variable changes the meaning of the latent variable (e.g., measuring "SES" without "Income" fundamentally changes the construct ). Conversely, in the reflective model, the constituents are the effect of the latent variable, and are therefore assumed to covary. Omission of one of its constituents would not redefine the construct.

Assuming the construct to be formative or reflective determines how to design the measurement instrument and how to test for validity. Construct misspecification is a highly debated topic in psychology and the social sciences. Measurement instrument validity depends on whether the latent construct is assumed to be formative or reflective. In the formative model, the latent variable is defined by the indicators, so "omitting an indicator is omitting a part of the construct" \citep{bollen1991conventional}. Omitting one indicator changes the meaning of the latent variable (e.g., measuring "SES" without "Income" fundamentally changes the construct). Conversely, in the reflective model, the indicators are the effect of the latent variable. This implies that the indicators must covary. Omitting one indicator would not redefine the construct, and they are interchangeable \citep{jarvis2003critical}.  

Consider the "Quality" construct ("Q\&A answer quality" in the case of \citet{li_using_2022}, and "marketing copy quality" in the case of Barter Deals). To determine whether \textit{Quality} is formative or reflective, we consider the direction of causality. Consider some indicators of text quality, such as fluency, tone, and relevancy. If \textit{Quality} were reflective, an increase in \textit{Quality} would cause an increase in all its indicators. However, this is theoretically incoherent. For example, by improving text relevancy \textit{Quality} can be improved, while retaining the same level of fluency. On the other hand, if we improve fluency, \textit{Quality} increases. Therefore, \textit{Quality} is considered to be a formative construct.

Explain the processing pipeline: we define the formative variable, and measure the subdimensions individually. We design a prompt that targets these subdimensions specifically. We have the LLM process the prompt (here there is a tree: some use CoT, reasoning models, etc., but we opt for single-token generation: it functions as a 'snapshot' of subjectivity, and is computationally more efficient, which is a very strict requirement if a model is to be used in production; arguably this is more methods however). Internally, the LLM processes the prompt. Generation in LLMs works by computing the conditional probability of each token in the vocabulary, given the previous tokens. This produces logits, or scores, which can be converted to probabilities using the softmax function. A distinction should be made between single-token generation and multi-token generation. Given a prompt, the logits are computed for the first next token. When the temperature $T=0$, the token with the highest logit in the set of allowed tokens is selected. This set can be the full token set (the entire vocabulary) for unconstrained generation, or a subset for constrained generation. For evaluation, generation would be constrained to e.g. set(1,2,3,4), corresponding to the possible values on a four-point likert scale. Multi-token generation adds a layer of complexity. Although the logits are deterministically computed, sampling is generally done stochastically. For example, first selecting low logit tokens might lead to a higher marignal probability if it leads to a sequence of high logit tokens. Methods like beam search allow efficient mapping of the probability space. However, for the current project, we specifically aim to investigate the logits, which are used to gain a better understanding of how the model processes the input. For multi-token generation, marginal probabilities would have to be estimated to obtain a reliable estimate of the model's internal representation of the construct, which adds a huge layer of complexity which we avoid. Moreover, single-token generation only requires a single forward pass, which is computationally cheap, and therefore best suited for production environments. 

After a single forward pass, the model's internal representation reflects its subjective evaluation of the target text, contained in the subset of constrained tokens corresponding to the target evaluation space.
